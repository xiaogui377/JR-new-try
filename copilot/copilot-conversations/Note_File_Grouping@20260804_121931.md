**ai**: 你可以手动或通过 Obsidian 设置实现附件的集中管理，下面是两种方式：

### 1. 推荐方式：使用 Obsidian 内置的“附件文件夹”设置
- 打开 **设置 → 文件与链接**
- 找到 **“新建附件的保存位置”**，选择 **“当前笔记所在文件夹下的指定子文件夹”**
- 在 **“子文件夹名称”** 中填写例如 `attachments` 或 `附件`
- 勾选 **“自动更新内部链接”**（这样移动后链接不会失效）

完成设置后，**新拖入或粘贴的 PDF、JPG 会自动存入该子文件夹**。

### 2. 整理已有的散落文件
如果你的笔记中已经引用了 `[[xxx.pdf]]` 或 `![[xxx.jpg]]`，但文件还散落在根目录或其他地方，你可以：

#### 选项 A：使用社区插件一键移动
安装 **“Clear Unused Images”** 或 **“Attachment Management”** 插件，它们可以：
- 扫描所有笔记内的附件链接
- 根据规则（如按笔记名建文件夹）将附件批量移动到指定位置
- 自动更新笔记中的链接

#### 选项 B：手动整理（适合文件较少时）
1. 打开笔记，点击右上角 **更多选项 → 文件 → 移动笔记到...**，将笔记本身移到新文件夹（Obsidian 会自动移动并更新相关联的嵌入文件）
2. 或者在文件列表中，将 PDF/JPG 直接拖入目标文件夹，Obsidian 会自动更新所有引用该文件的链接

如果需要更具体的操作协助（比如提供附件文件的清单或笔记链接情况），可以先用 `@vault` 搜索相关附件，我再帮你制定个性化的整理方案。
